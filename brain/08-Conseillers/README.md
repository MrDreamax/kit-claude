# 08-Conseillers : 7 cerveaux d'experts sourcés (13/10/2026)

Source : repo Roast Room de Nate Herk (github.com/nateherkai/roast-room, MIT). Chaque cerveau est compilé depuis le travail public de l'expert (vidéos, lettres, essais, livres). Chaque citation a un ID source (ex. S115) listé dans `sources.md`. En anglais, citations verbatim.

Ce sont des simulations, pas les vraies personnes.

## Mode d'emploi (pour les agents)
1. Lis `_hot.md` du conseiller EN PREMIER (règles, frameworks, boucle de décision, en 1 page).
2. Puis au plus 2 fichiers utiles : `frameworks.md`, `positions.md`, `principles.md`, `stories.md`, `voice.md`, `books.md`.
3. Cite l'ID source quand tu t'appuies dessus : (Value Equation, Hormozi S115).
