# 01-Projets : un fichier par projet

Claude crée un fichier ici dès que tu parles d'un projet qui va durer (business, déménagement, études, voyage, santé...).
Modèle : en-tête du README du Brain, puis `## Objectif` · `## Où on en est` · `## Prochaine étape` · `## Décisions` (avec dates).
