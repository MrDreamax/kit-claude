# Christian Peverelli : montage vidéo automatisé avec Claude Code
URL : https://www.youtube.com/watch?v=HzXD4GVqXwM (17 min, en français)
Thème : contenu / montage. Fiabilité : démo réelle, coût détaillé, mais une seule vidéo montrée. Intérêt : offre son skill dans sa communauté gratuite (fait de la promo).

## À ignorer
Tella, Epidemic Sound, montage de long YouTube avec animations (hors format reel).
## À vérifier
Chiffres de coût (jetons estimés par Claude lui-même).
## Comment l'appliquer
Après chaque reel : "apprends de ce montage et mets à jour le skill de montage". Lance le montage la nuit sur le rush du jour, relecture le matin.
