# Yassine Sdiri : Claude Skills, tout le monde peut automatiser
URL : https://www.youtube.com/watch?v=y4AAFTlA6ak (25 min, en français)
Thème : IA appliquée, closing (compte rendu d'appel). Fiabilité : pédagogie claire, démo complète. Intérêt : agence IA qui vend de l'implémentation.

## À garder
| Idée | Preuve | Utile ? | Effort |
|---|---|---|---|
| Skill = nom + description + mode d'emploi ; seuls nom et description sont chargés, le reste à l'usage, pour ne pas saturer le contexte (3:01-4:32) | affirmé | Oui : écrire des descriptions précises pour que tes skills se déclenchent | Rapide |
| Skill vs projet : le skill s'applique partout et s'améliore, le projet est isolé et statique (7:35-9:05) | affirmé | Argument pour choisir un skill plutôt qu'un projet | - |
| Skill = cerveau, connecteur = bras, plugin = pack de skills + connecteurs (10:37-12:08) | affirmé | Vocabulaire utile | - |
| Démo : après un appel prospect, un lien Fathom en entrée donne un devis PDF + proposition + brouillon Gmail à valider (15:11-22:45) | montré (démo) | OUI pour la vente : après chaque appel, brouillon de suivi et proposition avec les mots du prospect | Moyen |
| Boucle de test intégrée du créateur de skills : compare avec/sans skill, note les résultats (6:04) | affirmé | Utile pour vérifier qu'un skill apporte vraiment quelque chose | Rapide |
| 5 skills de départ pour un business : marketing, support client, création de contenu, vente/vision, finance (22:45-24:16) | affirmé | Cadrage d'un premier jeu de skills | - |
| Ne jamais envoyer sans validation (brouillons), contrôler les connexions (24:16) | affirmé | Cohérent avec le principe : l'humain envoie toujours | - |

## À ignorer
Canva, n8n/Make, plugins avancés, sous-agents détaillés.
## À vérifier
Fonctions décrites pour Claude chat (zip à importer) : sur Claude Code, les skills sont des dossiers.
## Comment l'appliquer
Skill "suivi post-appel" : lien de l'enregistrement du call en entrée, sortie = brouillon Gmail + récap des objections + prochaine étape. Rien ne part sans ta validation.
