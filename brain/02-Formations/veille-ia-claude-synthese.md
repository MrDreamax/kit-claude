# Veille IA / Claude : synthèse (2026-10-12)
15 vidéos (EN + FR), fiches : 02-Formations/veille-2026-10-12-*.

## Le cadre : les 4 C (Nate Herk, Build & Sell Claude Code OS, 12:00)
Système IA = Contexte + Connexions + Capacités + Cadence. Sert aussi de plan de livraison si tu installes un système IA pour d'autres.

## Comment l'appliquer
- Skills à créer : relance-leads (Saraev), calls-vers-contenu (Patrick Dang), drift (Greg Isenberg).
- Tâches planifiées : relance des leads deux fois par semaine ; analyse des appels dans la tâche contenu hebdomadaire ; drift + ménage de ta base de notes dans l'audit du dimanche.
- Base de notes : hot.md, index.md, log.md (wiki Karpathy via Nate Herk).
- Montage : boucle d'apprentissage regles-apprises.md (Peverelli).
- Canal d'erreurs : un fichier erreurs-taches.md (Saraev).
- Règles de base : plan + vérification avant un gros chantier (Boris Cherny), rien supprimé sans ton OK (Jeff Su), l'humain envoie toujours (Saraev).

## À décider avec prudence
- Permissions/deny + hook anti-suppression (touche la sécurité de Claude, à faire avec ton OK explicite).
- Routines cloud (quotas du plan à vérifier), montage de nuit (à tester sur la qualité réelle), speed to lead SMS en 1 min (RGPD), brief du matin (Gmail/Agenda à brancher).

## Si tu installes ce système pour d'autres
Onboarding 7 questions, audit /100 (25 par C), level-up, 3 critères de succès, prévenir un creux de ~20 % au début. Aucune vidéo ne donne prix ni pitch.
