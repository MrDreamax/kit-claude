# Modèles fournis

`face_landmarker.task` et `hand_landmarker.task` : modèles Google MediaPipe (licence Apache 2.0), utilisés en local pour trouver le visage et les mains (cadrage, sous-titres, tracking). Rien n'est envoyé sur Internet.
Le modèle de détourage RobustVideoMatting (licence GPL-3.0) n'est PAS fourni : `scripts/setup.sh` le télécharge sur ton ordinateur.
