# MONTAGE VIRAL : comparaison en T, mauvais / bien / excellent, tier list (VALIDÉ)

Lu après `SKILL.md`. Les 3 formats partagent le même moteur (`viral.py`), d'où un seul fichier.
Le tableau vit AU-DESSUS DE LA TÊTE, la face cam et les sous-titres restent visibles dessous (la version plein écran bleu a été écartée). Le format se décide au SCRIPT, pas au montage : la vidéo doit être écrite pour (comparaison « à ne pas faire / à faire », niveaux « mauvais / bien / excellent » en les montrant du doigt, classement « X, S tier »). Un seul tableau par vidéo (`t`, `mbe` ou `tier`).
**Prérequis tournage** : de la place au-dessus de la tête (haut des cheveux vers 37 % de la hauteur du cadre, donc cadrer plus large que d'habitude). Sinon le moteur en rajoute en fondu (mur du haut prolongé, cam descendue) et le tableau est plus serré. Dis-le à la personne AVANT qu'elle tourne si le script est écrit pour ce format.
Règles détaillées : en-tête de `viral.py`.

1. **Étape 1 SANS `cadre.py`** (il zoome et mange la place au-dessus de la tête) : simple mise au format `ffmpeg -i rush.MOV -map 0:v:0 -map 0:a:0 -vf "scale=1080:1920:flags=lanczos,fps=30" -c:v libx264 -crf 16 -c:a aac -b:a 192k rush.mp4` (iPhone : rotation appliquée toute seule). Puis étapes 2-3 (transcription, dérush) → `clip.mp4` + `words.json`. **Relire words.json mot par mot** : Whisper écrit « c'est tier » pour C tier, « bê / b » pour B, « à » pour A, « dé / d / des » pour D, « est » pour S ; corriger le texte (garder les timings).
2. **plan.json** : `cam`, `words`, `fixes`, `music` (émotionnelle), PAS de `title`, `bigwords`, `numbers` (ils occupent la zone du tableau) ; `keywords` possibles seulement si les sous-titres restent <= 1340 px (le script les retire sinon). + le tableau, calé sur SES mots (chercher l'instant de chaque mot dans words.json). **EXEMPLES FICTIFS** (remplace par les mots de la personne) :
   - **T** : `"viral": {"t": {"title": {"sans": "Un coach", "serif": "pour qui&#8239;?", "at": 0.68}, "bar_at": 1.15, "left": {"head": "PAS POUR TOI", "icon": "cross", "at": 2.40, "items": [["frimer", 3.70], ["te la péter", 5.04]]}, "right": {"head": "POUR TOI", "icon": "check", "at": 6.86, "items": [["entrepreneur", 7.72], ["tu crées<br>du contenu", 8.66]]}, "win": {"at": 10.06}}}` ; `title.at` = quand la personne annonce le sujet ; `bar_at` ≈ +0,5 s ; en-tête de colonne = le mot qui l'ouvre (« pas fait pour toi », « par contre ») ; élément = le mot exact ; `win` = sa conclusion (« oui, je te le recommande ») : la colonne perdante se grise et se barre, la gagnante grossit avec un halo. 2 éléments max par colonne, SES mots condensés (1-3 mots, `<br>` pour 2 lignes).
   - **Mauvais / bien / excellent** : `"viral": {"mbe": {"title": {"sans": "Ta bio", "serif": "Instagram", "at": 0.27}, "cards": [{"label": "Mauvais", "at": 1.02, "img": "ins/bio-mauvais.png", "text": "Floue"}, {"label": "Bien", "at": 1.71, "img": "ins/bio-bien.png", "text": "Une promesse"}, {"label": "Excellent", "at": 3.00, "img": "ins/bio-excellent.png", "text": "Promesse, preuve, action"}], "win": {"at": 3.6}}}` → 3 cartes de gauche à droite (l'ordre où la personne les montre du doigt), pastille couleur (rouge / ambre / bleu) + **IMAGE** qui illustre (des images pour illustrer, avec un petit texte juste en dessous) + petit texte serif dessous. Images = VRAIS exemples (fausse bio refaite en HTML puis capture Chrome, capture d'écran, produit) ; sans image → icône tracée (croix / vague / étoile). `win` = la meilleure carte s'allume (halo), les autres se grisent. Si la vidéo est très courte, garder 2-4 s après le dernier mot pour qu'on lise (la personne reste immobile avant de couper).
   - **Tier list** : `"viral": {"tier": {"title": {"sans": "Tier list", "serif": "des formats Instagram", "at": 0.15}, "rows": ["S", "A", "B", "C", "D"], "items": [{"img": "ins/podcast.png", "label": "Podcast", "text": "Podcast", "at": 1.95, "to": "S", "land": 2.56}, ...]}}` → rangées de couleur classique (S rouge, A orange, B jaune, C vert, D bleu). Titre en grand au début, puis il s'efface et le tableau prend toute la zone (`title_hide: false` pour le garder). Chaque élément = **ICÔNE + son nom DANS la tuile** (police de la DA) : grossit au CENTRE (220 px) quand il est nommé (`at`), file dans sa rangée quand la personne dit la lettre (`land`), la lettre s'allume. Construire `items` en lisant words.json : élément = mot qui le nomme, `land` = la lettre qui suit.
   - **Icônes de la tier list** (seule image générée de ce style) : avec Higgsfield, `gpt_image_2_5`, `background: transparent`, `quality: high`, `1k`, 1:1 (1,5 crédit l'une ; lots de 5 max, sinon limite de débit 429 = rien n'est débité, relancer). Prompt = « A single app-style icon, centered with generous margin, on a transparent background. Subject: <objet concret>. Flat 2.5D vector illustration with soft matte shading and gentle gradients, rounded geometric shapes, clean confident outlines. Limited palette: <4 couleurs de TA marque, depuis marque.json>. Soft key light from the top-left, a small soft contact shadow under the object. Clean edges with the background fully transparent around the object. Matte finish throughout. Wordless pictogram, no lettering. » Puis nettoyer le halo (alpha < 110 → 0). **Sans Higgsfield** : tes propres PNG à fond transparent (logos, captures détourées, objets photographiés), ou un emoji (champ `"emoji": "🎙️"` de l'élément à la place de `img`), ou du texte seul en pastille (secours) ; garde les icônes dans `~/Documents/Contenu/medias/photos/icones/` pour les réutiliser.
3. Place + moteur + tableau + rendu + son :
```bash
python3 $S/viral.py layout plan.json     # mesure la tête ; trop haute -> clip_viral.mp4 (cam descendue + mur prolongé en fondu) ; écrit cam / subY / viral.zone
node $S/build.mjs --plan plan.json --out index.html
python3 $S/viral.py inject plan.json     # pose le tableau (t | mbe | tier ; compact tout seul si la zone < 690 px)
node $S/zones.mjs .                      # zones mortes : « OK : 0 »
npx --yes hyperframes@0.6.81 render . -q high
python3 $S/mix.py plan.json renders/<x>.mp4 clip_viral.mp4 final.mp4
```
4. Vérifier (étape 7) : planche aux instants clés (titre, chaque élément, final) : chaque élément arrive sur son mot, rien ne touche la tête ni le trait, sous-titres sur le haut du torse (jamais sur le menton), pas de couture visible en haut.

Zone du tableau = entre 270 px (zone morte du haut) et le haut de la tête. Moins de 300 px = tableau serré (le script prévient) : au tournage, cadrer plus large.
Limites : zone < 420 px (plan très serré) = le tableau ne tient pas, le script le dit → retourner tourner avec de la place. Visage bas dans le cadre = sous-titres plafonnés à 1400 px, juste sous le menton. Pas de SFX sur les cartes ni sur les pastilles (à tester si l'utilisateur en veut).
